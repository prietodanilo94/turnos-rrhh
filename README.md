# TurnosRRHH — Sistema de Gestión de Turnos

Sistema web interno para gestión de horarios semanales de trabajadores en sucursales de venta.

## Stack
- **Backend:** FastAPI (Python 3.11)
- **Base de datos:** PostgreSQL 15
- **Frontend:** React + Vite
- **Deploy:** Docker Compose + Nginx

## Levantar
```bash
docker-compose up -d --build
```

## URLs
- API: http://localhost:8000/docs
- Frontend: http://localhost:3000
